Версия: 2.0
Описание:
Полностью переработанная версия. Добавлен графический интерфейс.Код структурирован с использованием классов.

Что сделано:
1. Постоянное хранение данных:
   - Используется встроенная база данных. Данные не теряются после 
     закрытия программы
2. Полноценный CRUD:
   - Добавление, просмотр, редактирование и удаление записей о книгах
3. Умный поиск:
   - Поиск работает по части названия, автору или году. Регистр не важен
   - Вывод результатов в виде аккуратной таблицы
4. Стабильность:
   - Реализована обработка всех ошибок (неверный ввод года, отсутствие данных)
   - Программа стала работать стабильнее при действии пользователя
5. Интерфейс:
   - Добавлено многоуровневое текстовое меню с подсказками
