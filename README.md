Название: shopsystem
Автор: Дудла Олеся
Версия: 1.0

Описание:
Приложение представляет собой консольный скрипт на Python. Реализован базовый 
ввод данных о книгах. Данные хранятся в оперативной памяти и теряются после 
завершения работы. Отсутствует обработка ошибок

Функциональность:
1. Добавление книги (название, автор, год)
2. Просмотр списка книг в виде неформатированного вывода
3. Поиск по названию (регистрозависимый, без подсказок)

Недостатки (почему версия сырая)
- Нет сохранения данных (все пропадает при выходе)
- Любая опечатка в команде приводит к аварийному завершению
- Невозможно удалить или отредактировать запись
- Вывод данных выглядит неструктурированно, сложно читается
- Отсутствует разделение прав доступа (админ/пользователь)
